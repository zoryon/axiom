# CS-101 — C Programming I lesson pack

This directory contains the authored lesson files declared by `content/courses/010-c-programming-1.course.json`.

Design principles:
- C language semantics first, machine observations second.
- Warnings, manual tracing, explicit contracts and boundary analysis from the beginning.
- No dynamic allocation in the capstone; heap ownership is intentionally deferred to C Programming II.
- Practice is embedded in each lesson and automatically indexed by AXIOM.
- Stable lesson/block IDs should not be changed after learner progress exists.

The course targets current standard C (C23 / ISO/IEC 9899:2024) while emphasizing portable constructs and calling out implementation-specific observations.
